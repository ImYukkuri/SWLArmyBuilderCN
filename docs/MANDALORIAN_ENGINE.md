## 隔离边界与停用

- 浏览器实现：`mandalorian-rules.js`，注册到可选的 `window.ArmyRuleExtensions`。
- Python 实现：`mandalorian_rules.py`，由 `rules.py` 的可选扩展表加载。
- 通用引擎只提供扩展接口：准备派生资料、可用性、军阶、单位上限、升级条件、费用差额、默认装备、军表校验、配置清理。通用引擎不包含氏族 ID、曼达洛卡名或五选二的具体效果。
- `BuilderModel` 通过通用接口取得默认装备并调用原有 `equip`，继续使用原槽位、唯一性和原子操作校验。
- 人员卡 `affiliationIds` 是卡自身资料；实际改变宿主组织仍由原有 `rules.addProperties/replaceProperties` 执行。两者不能混用。
- 如需停用整个模块：移除 `index.html`、`rules.html` 中的脚本引用及 `tools/build_public.py`、`server.py` 的对应资源登记；Python 从 `ARMY_RULE_EXTENSIONS` 移除该模块（也可移走模块文件，可选导入会回退）。通用接口保留为空实现即可。关闭单个配置只需移除其 `mandalorian` 启用数据，但这不代表对应氏族仍有完整规则支持。
- 模块停用不会改写已有存档；已有派生 ID 不应自动替换成普通卡。重新启用后恢复解析。原生 JSON 是完整备份方式。

## 已实现的组军行为

1. 雇佣兵计入最低军阶，跳过通常雇佣兵池上限，保留军阶上限。
2. 用装备后的组织寻找同组织指挥官或特工。尚未找到时允许继续组军，单位和军阶标红。移除头盔、换装和移除领导单位后重新检查。
3. 指定氏族为通用曼达洛单位自动选择唯一合法的同氏族头盔。有两个合法选项时不代选。自定义氏族保留通用组织，不提供改属其他氏族的头盔。
4. 曼达洛学徒通常最多 2 个；守望之子不设此额外上限。其装备的独特人员升级减 5 分。
5. 自定义氏族从五项中选两项；未选齐可继续编辑但显示校验问题。
6. 老兵只对 Mandalorian Warriors 的 `galaar-15-carbines` 每张减 5，不包括单数 Carbine 的其他升级。
7. 行当工具：`mc-tools-<原升级ID>` 三张独立免费副本，正常占槽，仅曼达洛人士兵可用。每张全军唯一；与普通付费副本的整军数量分别计算，同一单位仍不可重复同名卡。缆索放宽原指挥官／特工限制，特殊卡的效果预览移除被豁免的原限制句。
8. 雇佣火力：`mc-hired-<原单位ID>` 三个载具变体，全军合计最多 1 辆。复制雇佣兵 A-A5、雇佣兵 WLO-5 和现有帝国 TX-225，改组织为 1084，加入协同：曼达洛战士、独立：激增 1。源卡保持原样。
9. 取消规则或切换战斗部队时清除失效的赠送副本／派生载具，普通付费装备与其他单位保留并重新校验。
10. MC-G3、局内部署、英勇标记以及克里兹／雷恩／萨克森的战斗效果只展示规则，不模拟对局。

人员卡的原条件有部分丢失了卡面氏族图标。本模块只在启用范围内读取现有英文使用要求里的氏族图标，恢复组织限制，并保留 OR。例如 Tristan Wren 可用于萨克森或雷恩，不能误收窄为单个氏族。Tristan Wren 在当前单位资料中没有同名原卡；用户于 2026-11-17 明确确认其**自身组织同时记为萨克森（1083）和雷恩（1082）**，已标记为人工校对。自身组织与卡面的两种适用组织分别保存。

## 运行时数据和费用

派生资料仅在加载时深复制一次；不会写入原 `units.json` 或 `upgrades.json`。`runtimeVariant` 记录来源 ID、规则选项和类型。重复准备数据幂等。存档只保存选中 ID 与 `army.options`，重载后从同一来源重新构建。

卡片、槽位、单位总分、军表总分、首页军表摘要和导出使用同一 `upgradePoints` 计算。旧 `modifiedPointsWith` 中 Veterans / Children of the Watch 的折扣由模块接管，避免重复扣分或错误套到其他宿主。编辑器的价格仍显示卡面基价。

## 规则窗口与编辑

战斗部队选择框旁的信息按钮打开规则窗口，分别显示当前模式军阶最低／最高数量、组合上限、单位数量限制和特殊规则。原有 15 个部队的中文说明根据本地 `DOC56_BattleForces-3.pdf` 的各页规则块校核；氏族五个配置引用第 9、10 页并按用户确认调整组军语义。

编辑器可维护 `textRulesZh`、`textRules`、`unitLimitsText` 和选项 `text`。文字字段不自动生成机器规则；其他战斗部队既有引擎覆盖范围不因补充说明而变化。军阶配额仍由既有表单修改。

## TTS 与验证

六个曼达洛配置使用 `armyFaction: ""`，并使用标准英文 `battleForce` 名称；导入从战斗部队反推曼达洛势力。`listlink` 继续为空。TTS 名称格式不能表达五选二或免费／付费同名副本的区别，导出会明确提示同时保留原生 JSON，不臆造额外 TTS 编码。

验证包含 JS/Python 费用、军阶与异常码一致性，组织替换、自动头盔歧义、人员组织 OR、免费卡和付费卡并存、三选一载具、失效清理、原生源数据不变，以及模块停用后其他势力结果相同。真实浏览器检查桌面／手机选卡、规则窗口和编辑器保存重载；测试资料与截图均存放在仓库外。
