# 卡图与缩略图

- 升级卡：`assets.front` 是完整卡图，`assets.thumbnail` 是列表缩略图；背面在 `back.assets` 使用相同字段。
- 指挥卡、任务与优势卡：`image` 是完整卡图，`thumbnail` 是列表缩略图。
- 单位现有的裁剪肖像 `assets.portrait` 保持原用法。

缩略图位于 `assets/thumbnails/`，保持纵横比且不放大小图。升级卡宽度最多 360px，指挥卡和任务卡最多 480px，WebP 品质 82。文件名包含源图片内容摘要；换图后使用新路径，避免浏览器继续使用旧缩略图。

列表、圆形升级槽和编辑器列表使用缩略图。大图窗口使用完整卡图。双面卡的列表缓存仅加载缩略图；打开大图后才缓存两面的完整卡图。没有缩略图或加载失败时回退到原图。

任务／优势卡从 PNG 转为原始尺寸的 WebP，品质 92。升级卡与指挥卡原图不重编码。任务卡旧 PNG 在替换前备份到仓库外。

本地批量处理需要 Pillow：

```powershell
python tools/prepare_card_images.py --backup-dir <仓库外备份目录>
```

脚本同时更新数据引用，检查升级卡、指挥卡原图哈希未变。已有任务卡 WebP 不会再次压缩。编辑器上传图片或修改卡图路径时自动更新缩略图。生成的图片作为静态资源纳入版本管理，Pages 构建直接复制，不需要在 CI 安装 Pillow。
