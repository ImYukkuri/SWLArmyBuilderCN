# UI 约定

用户于 2026-11-23 指定。适用 SWLArmyBuilderCN；后续界面修改先检查此文件。

## 基本原则

- 优先优化手机使用；用布局、对齐、分区解释信息，避免不必要的标题、辅助标签和说明。
- 压缩无效留白，不靠隐藏卡牌信息或过度缩小字体节省空间。
- 色彩只用于明确指定的位置。当前仅批准单位选择卡的名称色块；不能据此给整张卡、所有按钮或整站背景染色。
- 保留已有卡图、词条、武器交互。正式 UI 实装前先给独立 demo，用户确认后再施工。
- 当前用户已要求暂停加载问题调查，本轮先做 UI。

## 单位选择卡布局

卡头贴卡片顶边和左边。左列加大单位缩略图，右列分四行。

1. 名称行：中文单位名称和英文名称放在同一块低矮的势力色底上，配同色系边框、极轻的渐变和小缺角。中文用字体更方正的现代黑体，字号略小。右侧保留大号分数、小号“分”和收藏按钮。“分”底对齐，其他文字和图标同一中轴线。窄屏优先保留中文名，长英文省略，完整内容保留在可访问名称／详情中。
2. 称号行：左侧中文称号＋英文称号，保持单行高度。英文排不下自然换到被裁掉的下一行。右侧依次是军阶图标、单位人数、中文军阶、单位类型。无称号时留空。
3. 属性行：防转格同时表示防御骰颜色，红防为红底，白防为白底。攻转格无转为白底、转命中为黄底、转暴击为橙底。格内保留图标。其余生命、勇气／韧性、速度沿用现有数据与图标。
4. 槽位行：槽位用带虚线边框的标签显示，图标在左，名称在右。宽度不足时整枚标签换行。专属槽去掉外层方头括号。

词条和武器依次铺满卡头下方宽度，使用紧凑一致的内边距。

- 槽位显示中的“重武器”统一简写为“重武”，单位选择卡和写表器主界面共用这一显示名称；不更改字段 ID、规则原文或武器名称。
- 词条沿用带颜色和文本的时机前缀，点开沿用简写／完整规则浮窗。选择面板顶部的“词条释义”复选框统一展开或收起单位及武器词条的内联简写。
- 武器沿用“近战可用武器”“远程武器”分类和已有黑底、距离、骰池样式，不改为另一套规则表现。
- 取消卡片末尾“点击加入军表”，保留整卡点击加入与功能按钮独立响应；武器后仅留小间距。
- 检查 320／360／390／430 px 手机及平板；长单位名、长称号、长类型名、无称号、五种组织色、双武器、密集词条均应可用。
