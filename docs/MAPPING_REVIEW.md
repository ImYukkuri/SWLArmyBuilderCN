# 现有映射适用性

已读取转换器中的单位名称、武器名称、三个关键词词典和升级卡映射，
作为本项目 `references/` 的独立快照；未修改原转换器任何文件。
unit-names.zh.json 继续保留原 117 条记录，并追加本地名称/称号组合供新项目复用。
未覆盖的中文名称/称号已补入本地初译文件；现有用户译名优先，不覆盖。

| 参考 | 用法 | 限制 |
| --- | --- | --- |
| 117 条单位名称/称号组合 | 精确英文、中文、称号与该单位武器名 | 不含属性；185 张卡并未全覆盖；同名跨版本不能只按名字合并 |
| 156 条审阅词条 | identifier、英文标题、中文标题、简写、完整规则、时机 | 有新卡关键词未收录；标题中的 X 需使用卡面实际参数 |
| 2 条单位补充词条 | Grogu 的 Hunted / Latent Power | 缺英文标题，用 identifier 生成搜索键 |
| 7 条战术卡补充词条 | 已有 Arm / Detonate / Area Weapon 等引用 | 不能推导不存在的规则 |
| 503 张升级卡 | 额外武器名称中英候选 | 禁止拿卡牌 cost、升级武器骰数覆盖单位卡数值 |

大小写和撇号通过归一化搜索键处理；记录写入映射中的准确英文。
武器近似匹配提高阈值并要求名称中的数字一致，防止 E-11 错配 E-11D、
Blaster Carbines 错配 DC-15A Blaster Carbine、DC-17 Blaster Pistols 错配其他型号。
规则原始识别字符串保存在 originalRaw 和 source.keywordRaw 中。

每张卡的 `mapping` 记录是否成功匹配、方法、分数和候选。
相同名称有新称号时，只可复用无歧义的中文名称，不能套用旧称号或旧武器。
中文未覆盖的条目保留英文。缺失规则集合集中于 `data/extraction-report.json`。

版面、识别结果及数字校正均未被标为整卡已审阅；用户校对后自行将
review.status 改为 reviewed。未来组军引擎必须在点数、升级槽与阵营合法性
校对完成后才使用这些记录判断军表是否合法。
